# Hero room sequence

The continuous room construction/furnishing sequence comes from the user-specified
reference: https://interior-design-nu-coral.vercel.app/sequence/frame_000.webp
through `frame_119.webp` (120 frames).

Locally optimized WebP variants:
- `desktop`: 1440 x 810, quality 80.
- `mobile`: 960 x 540, quality 76.

Frame 000 is the empty room. Frame 119 is the finished-room poster for reduced
motion. The canvas uses the same centered cover crop for every frame.
